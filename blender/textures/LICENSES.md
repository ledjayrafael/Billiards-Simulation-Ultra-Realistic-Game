# Lisensi tekstur

Semua tekstur di folder ini berasal dari **Poly Haven** (https://polyhaven.com) dan berlisensi
**CC0 1.0 (Public Domain)** — bebas dipakai tanpa atribusi. Diunduh oleh `tools/fetch-textures.mjs`.

| File | Aset Poly Haven | Dipakai untuk |
|---|---|---|
| `walnut_veneer_02_*` | https://polyhaven.com/a/walnut_veneer_02 | rail & bodi meja, furnitur |
| `herringbone_parquet_*` | https://polyhaven.com/a/herringbone_parquet | lantai |
| `plastered_wall_04_*` | https://polyhaven.com/a/plastered_wall_04 | dinding |
| `brown_leather_*` | https://polyhaven.com/a/brown_leather | liner pocket, bangku, wrap stik |
| `white_maple_veneer_*` | https://polyhaven.com/a/white_maple_veneer | shaft stik |

Tekstur lain (kain meja, atlas angka bola, lukisan dinding) dibuat prosedural oleh script di
`blender/scripts/` — tidak ada sumber eksternal. Angka bola memakai font bawaan Blender
(Bfont / DejaVu Sans, lisensi bebas Bitstream Vera).
