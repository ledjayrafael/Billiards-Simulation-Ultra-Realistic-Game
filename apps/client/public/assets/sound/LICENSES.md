# Lisensi suara

Efek suara tumbukan bola–bola, bola–cushion, tip stik, break, bola masuk pocket dan bola mendarat di slate
memakai **rekaman asli dari Freesound.org berlisensi Creative Commons 0 (domain publik)**. Lisensi dibaca di
halaman masing-masing suara pada 2026-11-18. CC0 tidak mewajibkan atribusi; daftar ini dicantumkan sebagai penghargaan.

Berkas di folder ini adalah potongan pendek (one-shot) dari preview HQ Freesound: dipotong per kejadian,
di-highpass, diberi fade, dinormalisasi, mono 16-bit 44.1 kHz. `sounds.json` memetakan bank suara ke berkas.
